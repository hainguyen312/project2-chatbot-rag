\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}
Citizens and businesses in Vietnam frequently need to look up the law, yet the body of legal documents is large, changes often and is written in specialised language. Existing lookup tools mainly rely on keyword search and therefore require users to know legal terminology in advance, while chatbots built on large language models answer fluently but may fabricate provisions or cite documents that are no longer in force. Retrieval-Augmented Generation (RAG) partly addresses this by letting the model read relevant documents before answering, but a fixed, single retrieval step often misses related provisions or recent amendments.

This thesis combines RAG, a knowledge graph and an AI agent on top of the Vietnamese Legal Code (Bộ Pháp điển) compiled by the Ministry of Justice, chosen because it is an official source that is already organised by topic and links related provisions. The system consists of a pre-processing layer that classifies requests, a tool-calling agent that decides when to run hybrid search (dense vectors combined with BM25 through reciprocal rank fusion), expand along the provision graph, read full provisions and check current regulations on the web, and a long-term memory with privacy controls. Beyond question answering, users can upload a contract to receive a summary and warnings about clauses that may violate the law; a warning is issued only when it is grounded in a provision that was actually retrieved, together with a verbatim quotation that the system verifies.

The main contributions are a hybrid retrieval method for Vietnamese legal text, a citation-verification mechanism for contract review, a privacy-aware long-term memory and an administration tool for legal documents that tracks their validity. On a set of 50 questions judged blindly by a language model, hybrid retrieval raises nDCG@10 from 0.417 to 0.632 compared with the initial dense retrieval; the agent calls every mandatory tool in 97.6\% of cases, and the memory module passes all 14 test scenarios without leaking sensitive data.
